
# Dota 2 Match Prediction

ML-пайплайн для предсказания победителя матча Dota 2 по первым 15 минутам игры. Данные — логи матчей с событиями, героями, регионами и чатом. В рамках проекта проведён разведочный анализ, собраны и сравнены признаки: агрегации временных рядов (mean/std/max/min/slope), кодирование категориальных признаков и извлечение сигнала из текстового чата через TF-IDF.

Качество моделей оценивалось на отложенном периоде (out-of-time), чтобы проверить устойчивость результата на новых данных. Сравнивался вклад разных групп признаков в итоговое предсказание.

## Признаки

- Агрегации временных рядов: mean, std, max, min, slope
- Кодирование героев и регионов
- TF-IDF по тексту чата с лемматизацией
- Бинаризация по минутам: early / mid / late

## Стек

Python, Pandas, Scikit-learn, Optuna, NLTK, CuML
